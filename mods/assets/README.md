# 随包运行资源

`public/art/rhine/` 和 `public/art/kazdel/` 会在候选构建时复制到游戏的 `public/art/`。这些图标和装置图用于更多阵营玩法；其来源、生成方式及第三方素材权利边界记录在各来源项目和上游 NOTICE 中。PNG 装置图为 AI 辅助生成，不宣称获得官方授权或独占权利。卡兹戴尔与莱茵图标为本项目几何绘制或用户提供标志的改绘，底层名称、商标及受保护形象仍归对应权利人。

这些文件独立于 `patches/modpack-code.patch`，不会混进上游代码补丁。更多阵营来源与移植范围见 [玩法说明](../../docs/MORE-FACTIONS.md) 和 [来源与署名](../../notices/SOURCES.md)。
