# 额外干员包

望、赤刃明霄陈、凯尔希·思衡托、维什戴尔；与更多阵营共用时采用卡兹戴尔维什戴尔。

独立选择，默认关闭。放入本仓库构建的0.3.1宿主 plugins/lele-recruits/，由房主在官方插件面板选择。

需要 Lele 宿主适配 API 1，尚非纯原版即装即用插件。没有该适配时，官方检查器会以 PLUGIN_PATCH_PATH 拒绝启用。共享引擎在宿主适配层，功能数据随本插件锁定；不要把插件文件覆盖到游戏源码。
