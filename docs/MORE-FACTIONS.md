# 更多阵营：莱茵生命与卡兹戴尔

本扩展适配上游 **0.2.2**，在大厅和等待室以“更多阵营”勾选项启用，默认关闭。最多四人；房主可在等待室切换，无需重建房间。它沿用历史协议键 `rhineEnabled` 和资料集名 `rhine`，以兼容既有房间与部署脚本。

## 莱茵生命

阵营保留原有干员和层数成长方式，并加入星源、多萝西等新干员。研究装置包括生态维持仪、能量谐振仪，以及九名莱茵成员时解锁的激光钻机：

- **生态维持仪**结合治疗、减速、护盾和束缚效果。
- **能量谐振仪**随研究阶段提升充能与脉冲效果。
- **激光钻机**锁定面板生命值最高的敌人，持续增伤并附加少量百分比真实伤害。
- **谬因**归入莱茵资料集，只开放五阶普通／精锐二技能；波束覆盖整条直线，中继器持续 25 秒。友军波束折射作了简化，三技能未开放。

科研研究在服务器结算，断线重连沿用当前进度。装置数量、技能选择与层数细节以游戏内说明和当前代码为准。

## 卡兹戴尔

卡兹戴尔有十名阵营成员，按 3／6／9 名在场成员解锁能力。重复干员不重复计入阵营人数；战斗开始时确定档位，阵亡不会降低本场档位。

- **3 人：众魂与死魂灵。** 卡兹戴尔干员首次真正倒地可召唤死魂灵。死魂灵不增加人口、不重复产层，复活／重新部署或战斗结束时消失。
- **6 人：死魂灵大炮。** 场外炮击敌方密集区域，同时可能误伤友军。
- **9 人：炮击不再伤害友军。** 其他战斗规则保持不变。

层数、召唤物继承范围、炮击伤害与充能的完整数值见来源项目和 [固定来源提交](../notices/SOURCES.md)。这些数值是本扩展玩法设计，不代表《明日方舟》官方卫戍协议设定。

## 与其他拓展组合

更多阵营关闭时使用干净原版资料；只启用本扩展时，莱茵与卡兹戴尔共同进入 `rhine` 资料集。若同时启用额外干员包，维什戴尔只保留卡兹戴尔版本，避免重复进入牌库。八套资料分别生成，等待室切换后客户端完成资料载入才可开始。
