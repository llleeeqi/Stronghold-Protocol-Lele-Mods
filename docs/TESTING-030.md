# 0.3.0 插件宿主验证记录（2026-10-16）

本次围绕插件更新后的完整使用路径验证。对局使用真实战斗引擎；浏览器验证使用独立身份和房间。

| 范围 | 操作与结果 |
|---|---|
| 选择与加载 | 两名独立浏览器，逐项加载八个插件，组合→关闭回原版→另一组合；勾选不发请求，确认只应用一次 |
| 联机准备 | 插件变更清除队友准备；两端内容校验通过后才能开局；不改动的选择不重新加载 |
| 刷新重连 | 手机横屏尺寸客户端，等待室刷新保留房间与内容；局内刷新保留棋盘并恢复对局 |
| 局内交互（首次检查） | 购买与部署使用协议请求，部署后的详情使用真实鼠标点击；这一步不能证明拖放交互正常 |
| 拖放专项复测 | 无插件与八项全开各建双人房：桌面鼠标、手机横屏模拟触摸事件，拖起备牌→放到棋盘→滑动朝向轮盘→核对服务端棋盘实际存在该干员；均成功。覆盖主渲染器和因加载超时启用的简化棋盘，不等于覆盖所有实体手机 |
| 失败与慢加载 | 模拟一次应用失败，八项选择仍保留、房间保持原版；再次应用成功。人为延后内容索引响应时，加载按钮保持禁用，校验完成再退出面板 |
| 战斗与奖励 | 双人真实服务端对局完成第一轮战斗和奖励，进入第2回合 |
| 完整回合流程 | 本地虚拟时钟驱动真实引擎：原版到第14回合RESULT，八项全开到第18回合RESULT；256MiB Node堆下均完成，错误数为0 |
| 内存缓存 | 连续切换十二组配置，房间持有一份时服务仅保留最多两份快照；线上修复后测试期间未再出现OOM或自动重启 |
| 定向检查 | 内容集服务3项、朋友服环境下子进程IPC3项、文档32项通过 |

复测方法：创建双人房间，队友先准备；房主更改组合并加载，核对队友准备被清除。逐项测试八个插件，关闭回原版，再同时启用八项。两端校验并重新准备后开局，购买和部署、打开详情、刷新重连，再完成战斗和奖励。最后清理测试房间，检查健康状态、容器重启计数与内存事件。

完整回合流程在本地加速，浏览器在真实服务器验证至第2回合；以上记录不等于穷举每名干员、每件收藏品及全部插件组合。

专项复测仍捕获过 `render engine import timed out` 警告，页面随后启用简化棋盘；落子成功不能据此认定用户反馈的部署故障已解决。当前未复现该故障，尚无已确认根因或对应修复。
